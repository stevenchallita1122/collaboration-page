This is the second page.

We made this website to practice working together with Git. Each of us can make changes on our own computer, then share them so the other person can get the latest version.

The site is made of three simple pages that all use the same stylesheet. Changing one colour or font in the CSS file updates it on every page, so everything stays consistent.

It is still a small project, but it is a good way to learn the basics of HTML, CSS and collaboration. We will keep adding to it as we learn more.
